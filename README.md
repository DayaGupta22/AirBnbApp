# 🏠 Airbnb Backend

A backend application inspired by Airbnb, built to provide a robust foundation for a property rental and booking platform.

The project provides RESTful APIs for managing users, properties, bookings, authentication, payments, and other core rental-platform functionality.

## 🚀 Tech Stack

* Java
* Spring Boot
* Spring Security
* Spring Data JPA
* Hibernate
* PostgreSQL
* REST APIs
* JWT Authentication
* Maven

## ✨ Key Features

* 🔐 User registration and authentication
* 👤 User and role management
* 🏠 Property/listing management
* 🔎 Property search and filtering
* 📅 Booking and reservation management
* 💳 Payment integration
* 🔒 JWT-based security
* 🗄️ PostgreSQL database integration
* ⚠️ Global exception handling
* ✅ Request validation
* 📄 Pagination and sorting
* 🔄 RESTful API architecture

## 🎯 Project Goal

The goal of this project is to design and develop a real-world, scalable backend similar to an Airbnb-style property rental platform while following clean architecture and modern Spring Boot development practices.

## 📌 Status

🚧 This project is currently under development. New features and improvements are being added continuously.
